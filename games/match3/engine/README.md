# Gem Swap rules engine attribution

`houseki-gem-swap/gem-swap/` contains the headless Gem Swap rules engine from
[Houseki](https://github.com/johnmorrisdotca/houseki), version 0.5.0, by John Morris. It is used
for board creation, legal swaps, cascades, gravity, refill, challenge goals, and deterministic
seeded simulation. The upstream `LICENSE` is preserved alongside the code.

The campaign content, demo UI, and bundled artwork were not copied. The adapter is our own
integration layer and uses original level metadata and the `Gem Garden` name.
