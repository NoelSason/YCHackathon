Plug Level AI into your tools

Your coding agent can order work from us without leaving your editor. Ask it for a playtest, a read on your reviews, or a free set of levels, and the results come to your inbox.

Get an API key See what your agent can do

Set it up in two steps

Level AI works with any coding agent that supports MCP (Model Context Protocol) servers over HTTP.

  1. 1

    Get an API key

    We email your key to you. It lets your agent order work on your studio’s behalf.

  2. 2

    Connect your agent

    Add Level AI to your agent’s MCP settings, then replace YOUR_KEY with the key from your email.

    MCP config (JSON) 
    {
  "mcpServers": {
    "levelai": {
      "type": "http",
      "url": "https://levelai.vercel.app/studio-mcp",
      "headers": {
        "Authorization": "Bearer YOUR_KEY"
      }
    }
  }
}
    Claude Code (terminal) 
    claude mcp add --transport http levelai https://levelai.vercel.app/studio-mcp --header "Authorization: Bearer YOUR_KEY"

    Then ask your agent something like “Get a Level AI playtest of my app.”

What your agent can do

Four tools. Your agent picks the right one from what you ask for.

  • Order a playtest

    request_playtest

    Plays your app on a real iPhone and emails you a report.

  • Read your reviews

    audit_reviews

    Reads your game’s newest Google Play or App Store reviews and says where players get stuck or bored.

  • Ask for free levels

    request_free_levels

    Asks for a free sample set of levels for your game.

  • Check on a request

    get_status

    Tells you where a request is and what’s done so far.
